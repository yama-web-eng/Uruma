Unitをえらぶ

Unitをえらんでねテスト範囲のUnitを選んで練習しよう。まずは基本コースで、必ず覚えたいルールを確認!
中学1年生
Unit 1えらぶ ›
  • 1-1I'm[I am] ~
  • 1-2I like ~ / I don't like ~
  • 1-3I can ~ / I can't ~
Unit 2えらぶ ›
  • 2-1You are ~ / Are you ~? と答え方
  • 2-2Do you ~? と答え方
  • 2-3Can you ~? と答え方
Unit 3えらぶ ›
  • 3-1What do you ~? と答え方
  • 3-2I like ~ing
  • 3-3I want to ~
Unit 4えらぶ ›
  • 4-1This[That] is ~ / She's[He's] ~
  • 4-2Who's[Who is] ~? と答え方
  • 4-3Is this[that] ~? と答え方 / This[That] is not ~
Unit 5えらぶ ›
  • 5-1命令文 / 否定の命令文 / Let's
  • 5-2Where is ~? と答え方 / Where do ~? と答え方
  • 5-3When is ~? と答え方 / When do ~? と答え方
  • 5-4ふくしゅう(Where ~? / When ~?)
Unit 6えらぶ ›

  • 6-3三人称単数現在の否定文
  • 6-4ふくしゅう(三人称単数現在)
Unit 7えらぶ ›
  • 7-1一般動詞の過去形(規則動詞・不規則動詞)

  • 7-3感嘆文(What a ~! / How ~!)
  • 7-4be動詞の過去形
